# Vehicle Wash App 🚗🫧

A modern full-stack Vehicle Wash Management System designed to simplify vehicle wash bookings and service management. The application allows customers to register, manage their vehicles, book wash services, and track appointments, while administrators can efficiently manage users, services, bookings, and payments.

## Features

- 🔐 JWT Authentication
- 👤 User Registration & Login
- 🚗 Vehicle Management
- 📅 Wash Service Booking
- 🧾 Booking History
- 💳 Payment Integration (Coming Soon)
- 📊 Admin Dashboard
- 📱 Responsive React Frontend
- 🔒 Secure REST API
- 🐳 Dockerized Development Environment

## Tech Stack

### Backend
- Django
- Django REST Framework
- PostgreSQL
- Simple JWT
- Django CORS Headers
- Python Decouple

### Frontend
- React.js
- Tailwind CSS
- Axios

### DevOps
